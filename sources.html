Every claim traces back to one of these

Three source classes are used and labelled: Official (the venue, operator or authority itself), Official booking partner (a page the MICHELIN Guide links as that restaurant’s booking channel) and Rate aggregator (a dated price snapshot, never used for anything except price).

Register

Source hierarchy used

1 · Official

Used for: distinction, address, hours, prices, rules, fares.

guide.michelin.com · metmuseum.org · 911memorial.org · rockefellercenter.com · mta.info · hotel and restaurant sites.

2 · Official booking partner

Used only where the official record did not print a field — typically the social handles and the cancellation policy.

resy.com venue pages, linked from the MICHELIN record itself.

3 · Rate aggregator

Used only for the dated price of a specific date range, and only with the exact URL and capture date published alongside.

booking.com. Never used for hours, amenities or ratings on this site.

Sources that were tried and failed

These were attempted and produced nothing usable. They are recorded so the next pass does not repeat the attempt blindly — each needs a JavaScript-enabled browser session instead.

  • le-bernardin.com/menus/ — returned a single gallery image; menu text is client-rendered. No price captured (F-06).
  • elevenmadisonpark.com — returned a slide carousel; no hours, price or social links in the text (F-06).
  • moma.org/plan-your-visit/ — page failed to load twice (F-07).
  • thehighline.org/visit/ — returned only a cookie-consent notice (backlog).
  • amnh.org/plan-your-visit — loaded, but hours live on a separate page that was not opened (backlog).
  • MICHELIN map views (?showMap=true) — coordinates are rendered client-side, so no geodata could be extracted (F-01).
  • perseny.com — HTTP 500; the MICHELIN record’s own link (thomaskeller.com/perseny) was used instead.

Reproducing this research

  1. Open any source above and search the page for the value quoted in the table.
  2. For prices, use the exact Booking.com URLs in the register — they carry the checkin=2027-02-15 and checkout=2027-02-22 parameters, so the dates reload automatically. Expect the figures to have moved; promotions expire.
  3. For MICHELIN distinctions, use the filtered list URLs rather than the general restaurant search — the filter counters (5 / 14 / 50 / 76 / 224) are the authority for the counts on this site.
  4. For any value marked unverified, there is nothing to reproduce from this site — the flag page names the page that would supply it.
