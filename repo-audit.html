Findings

Decision taken on publishing

Pages serves main at the repository root

Because the Pages source is main /, a site placed in /docs would not be served without reconfiguring Pages. The site therefore lives at the repository root (index.html plus one page per topic and an assets/ folder), which publishes on merge with zero configuration change. The trade-off is that build-source files sit next to the published pages — acceptable for a static, dependency-free site.

No external dependencies at all

The site uses one stylesheet, three scripts and no CDN, no fonts, no analytics, no cookies. That keeps the Pages build trivially reproducible and means a blocked CDN can never break the page.
