2 · Findings

R1 — the repository was effectively empty. A public repo whose only content is an 8-byte README gives a reader nothing and gives a crawler nothing. Everything on this site is new work; nothing existed to reconcile.
  • R2 · No licence. A public repository with no licence grants no reuse rights and leaves the provenance of compiled data ambiguous. Fixed: LICENSE — MIT for code, CC BY 4.0 for data and prose, with third-party marks explicitly excluded.
  • R3 · No .gitignore. Nothing stopped editor folders, OS files or local caches from being committed. Fixed.
  • R4 · No CI. Pages publishes whatever reaches main, so a typo in a JSON file or a broken relative link ships silently. Mitigated: scripts/verify.py checks local links, JSON validity, and that every row carries a source URL.
  • R5 · Pages serves main at the repository root. A site placed in /docs would not be served without reconfiguring Pages, so the site lives at the root. A .nojekyll file prevents Jekyll from processing the folder.
  • R6 · No branch protection. Two sessions pushed to the same repository the same day. Coordination therefore relied entirely on the board and on merge discipline, not on the platform.
  • R7 · Both sessions created COORDINATION.md independently. Neither saw the other's claim. This is the structural weakness the board is meant to prevent, and it happened because both sessions started from the same empty commit.

4 · What the merge changed, and why it is an improvement

  • Flag F2 was resolved, not deleted. Session A marked "no verified 7-night hotel total" as High severity. Session B produced four such totals. The flag was re-graded to Low and rewritten to say what is now known, what remains open (eight of twelve candidates unpriced, no cross-week comparison), and where the evidence is.
  • A new flag was raised against the new data: F10. The totals are aggregator snapshots and one depends on a promotion expiring 31 Dec 2026. Adding data created a new way to be wrong, so it was flagged on arrival.
  • Independent hours agreement was recorded, not hidden. Le Bernardin, Eleven Madison Park, Per Se and Atera were read separately by both sessions against the same MICHELIN records and agree. That is the strongest verification obtainable without a second source, so it is stated in data/restaurants.json.
  • The Le Bernardin gap closed. Session B could not capture Thursday–Sunday hours; Session A had them, including "Sunday closed". Session A's fuller capture is retained.
  • A two-star restaurant was added. Atera ★★ was missing from Session A's 20-row catalogue despite being on the official two-star list. Session B's verified record (77 Worth St, Tribeca; different service window every day) was appended.
  • Two official Instagram/Facebook accounts were added. Both were printed on the Resy venue pages that MICHELIN links as those restaurants' booking channel, upgrading those rows from third-party video only to verified official accounts.
  • The MTA fare was corrected to $3. Cached guides still quote $2.90; the official fares page read 2026-11-25 says $3 for subway and local bus, $7.25 for express. Raised as F12.
  • No prose was discarded silently. Where Session B's wording was kept (the hotel price notice, the executive-summary bullet on hotels), the file still carries Session A's structure and navigation.
